== Description ==
إضافة ووردبريس ثورية تعمل بالذكاء الاصطناعي (AI Vision) لتحويل صور المنتجات الخام إلى منتجات ووكومرس (WooCommerce) متكاملة. تقوم الإضافة تلقائياً باستخراج اسم المنتج، كتابة وصف تسويقي، تحسين وتعديل مقاسات الصورة، ونشر المنتج مباشرة في متجرك بضغطة زر.

== Installation ==
1. قم بضغط مجلد الإضافة باسم 'woo-ai-vision-publisher.zip'.
2. من لوحة تحكم ووردبريس، توجه إلى "إضافات" -> "أضف جديد".
3. قم برفع المجلد وتفعيله.
4. اذهب إلى قائمة "الناشر الذكي بالذكاء الاصطناعي" المضافة في الشريط الجانبي لضبط مفاتيح الـ API والبدء في نشر المنتجات بصرياً.
